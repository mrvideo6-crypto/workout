# Трекер тренировок (PWA для iPhone)

Приложение работает в Safari и ставится на экран «Домой». Данные хранятся на телефоне, интернет нужен только для первой загрузки.

## Как выложить в интернет (бесплатно, GitHub Pages)

1. Зарегистрируйтесь на https://github.com (если нет аккаунта).
2. Нажмите «+» вверху справа → **New repository**. Название, например, `workouts`. Выберите **Public**, нажмите **Create repository**.
3. На странице репозитория нажмите **uploading an existing file**.
4. Распакуйте архив на компьютере и перетащите **все файлы** (index.html, style.css, core.js, ui.js, i18n.js, exlib.js, sw.js, manifest.webmanifest и три PNG) в окно браузера. Нажмите **Commit changes**.
5. Откройте **Settings → Pages**. В разделе Branch выберите `main` и папку `/ (root)`, нажмите **Save**.
6. Через 1–2 минуты вверху страницы появится адрес вида `https://ваш-логин.github.io/workouts/`. Откройте его.

Адрес сайта будет публичным, но ваши данные на сервер не попадают: всё хранится только в вашем телефоне. Если не хотите, чтобы кто-то мог открыть пустое приложение, используйте непримечательное название репозитория.

## Как поставить на iPhone

1. Откройте адрес **в Safari** (в других браузерах «На экран Домой» может не работать полноценно).
2. Нажмите кнопку «Поделиться» (квадрат со стрелкой).
3. Выберите **На экран «Домой»** → **Добавить**.
4. Запускайте приложение с иконки. При первом запуске подтвердите доступ к камере, когда будете делать фото.

## Напоминания

- Приложение показывает умные подсказки на главном экране (сегодняшний день программы, пропуски, пора поднять вес, пора сделать фото).
- Уведомления на телефон идут через Календарь: в программе нажмите «Добавить в Календарь», в Фото (Тело → Фото) — то же. iOS откроет файл, нажмите «Добавить все». Удобнее сначала в настройках выбрать время напоминаний.

## Важно знать

- **Резервная копия:** Настройки → «Экспорт данных», сохраните файл в «Файлы» или iCloud Drive. Фото в копию не входят.
- Если долго не открывать приложение, iOS может очистить данные веб-приложений. Делайте экспорт раз в месяц.
- Фото хранятся в памяти приложения на этом телефоне. Удаление иконки с экрана «Домой» удалит и данные.
- Таймер отдыха работает, пока приложение открыто. При сворачивании звук не прозвучит, но при возвращении таймер покажет верное время.

## Как пользоваться программами

1. Вкладка «Тренировки» → «+ Новая программа». Для каждого дня недели введите название тренировки и добавьте упражнения («+ Упражнение») или кардио («+ Кардио»). День без упражнений считается отдыхом.
2. Для каждого упражнения задайте подходы, повторения, рабочий вес и порог «Повысить при». Программу можно править в любой момент (✎) и создавать несколько.
3. Кнопка «Тренироваться» предлагает выбрать программу и открывает тренировку на сегодня с уже заполненными значениями.
4. Когда во всех подходах упражнения повторений не меньше порога, приложение предложит повысить вес (шаг задаётся в настройках упражнения, по умолчанию 2,5 кг). Не чаще, чем раз в N дней (Настройки, по умолчанию 14).

## Библиотека упражнений и техника

При добавлении упражнения («+ Упражнение» или «+ Кардио») внизу есть библиотека на 100 упражнений: гантели, отжимания и подтягивания, штанга, тренажёры и блоки, кардио. Её можно искать и фильтровать по группам мышц. Значок ⓘ открывает краткую технику и частые ошибки, кнопка «Видео с техникой» открывает поиск видео на YouTube (нужен интернет). Значок ⓘ есть и в тренировке, и в программе. Подсказки общие и не заменяют тренера. Список можно править в файле `exlib.js`.

## Обновление приложения

Замените файлы в репозитории новыми и увеличьте номер версии в `sw.js` (в этой версии уже `wt-v7`; в следующий раз ставьте `wt-v8` и так далее). Данные на телефоне сохранятся, старые программы преобразуются автоматически.
